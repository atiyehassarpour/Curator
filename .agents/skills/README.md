# Curator Project Skills

Eight repository-scoped Agent Skills for repeatable work on the Contemporary Art Study Group.

## Included skills
- `art-direction` — visual identity, art direction, imagery, and visual consistency
- `premium-ui-ux` — responsive UX, interaction design, accessibility, and usability review
- `editorial-design` — curatorial writing, article presentation, and editorial integrity
- `nextjs-fullstack` — Next.js/TypeScript implementation and engineering practices
- `bilingual-rtl-ltr` — Persian/English localization, RTL/LTR, and bilingual QA
- `database-cms` — PostgreSQL domain model, CMS, and editorial lifecycle
- `security-testing` — security, privacy, authorization, and quality assurance
- `github-project-management` — safe branching, commits, documentation, and pull requests

## How to use
- **Codex:** open this repository as the working project. Codex discovers repository skills under `.agents/skills/`; invoke one with `$skill-name` or allow matching skills to be selected automatically.
- **ChatGPT desktop:** standalone skills are supported in eligible environments. Availability depends on account, workspace, and product surface.
- **ChatGPT web/mobile:** repository files do not automatically install skills into every ChatGPT surface. Use the Skills interface if enabled for the account, or package skills as an installable plugin for wider ChatGPT/Work distribution.

## Project governance
- Read the root README and approved project documents before acting.
- Skills do not override explicit user instructions or approved product scope.
- The current implementation milestone remains the homepage in four review states: Persian desktop/mobile and English desktop/mobile.
- Do not build internal pages, directories, CMS, authentication, admin, or infrastructure until explicitly approved.
- Do not provision paid services, create cloud resources, deploy, or perform destructive Git operations without explicit approval.
